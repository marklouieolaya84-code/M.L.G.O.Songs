# M.L.G.O

**Local music player** — connect one folder of songs and play them with true no-repeat shuffle.

## Features

- **Connect Folder** — select a single folder that contains all your music. New files you drop into that folder appear automatically when you reconnect.
- **True shuffle** — every song plays exactly once before the list reshuffles. The first song of a new cycle is never the same as the last song of the previous cycle.
- **Autoplay** next track
- **Liked Songs** — heart any track; likes are saved in the browser
- **Search**, Songlist, Home
- Works fully offline after the page is loaded
- Dark modern UI inspired by music apps

## Supported formats

`.mp3` · `.m4a` · `.wav` · `.ogg` · `.flac` · `.aac` and other browser-supported audio formats

## How to use (easiest)

1. Download or clone this repository
2. Open `index.html` in **Chrome**, **Edge**, or **Firefox**
3. Click **Connect Folder** and choose the folder where your music lives
4. Press play or **Shuffle Play**

> Tip: On first visit the browser may ask for permission to access the folder. Allow it.

## Host on GitHub Pages (optional)

1. Create a new repository on GitHub
2. Upload the files in this folder (`index.html` + this `README.md`)
3. Go to **Settings → Pages**
4. Set source to the `main` branch and `/` (root)
5. After a minute your app will be live at:  
   `https://YOUR_USERNAME.github.io/REPO_NAME/`

You can then open that link on your phone or computer and use it like an app.

## Install as an app (phone / desktop)

- **Chrome / Edge**: open the page → menu → **Install app** / **Add to Home screen**
- **Safari (iPhone)**: Share → **Add to Home Screen**

No servers, no accounts, no tracking.  
Your music never leaves your device.
