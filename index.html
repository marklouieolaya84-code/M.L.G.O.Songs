Music Folder

No folder connected. Click “Connect Folder” to select a directory that contains your audio files (.mp3, .m4a, .wav, .ogg, .flac).

How it works

1. Click Connect Folder and choose the folder where you keep all your downloaded music.

2. The app scans that folder and loads every supported audio file.

3. When you add new songs to the same folder, just reconnect (or refresh) and they appear automatically.

4. Shuffle mode plays every song exactly once before reshuffling, so the first song of a new cycle is never the same as the last song of the previous cycle.
